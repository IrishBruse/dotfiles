## Workflow

1. **Plan & Decouple:** Break the feature request into independent, modular tasks.
2. **Define Contracts:** Establish clear interfaces and data structures between components before execution.
3. **Execute Parallelly:** Assign tasks to specialized subagents to work concurrently in isolation.
4. **Integrate & Verify:** Merge the components, resolve any conflicts, and run end-to-end verification.
